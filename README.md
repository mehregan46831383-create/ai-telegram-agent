# AI Telegram News Agent

نسخه پایه یک بات تلگرامی برای انتشار خودکار اخبار AI، رباتیک و Prompt روز.

## راه‌اندازی
1. بات را در گروه Admin کنید و Send Messages را بدهید.
2. Token را در Secret/Environment Variable سرویس اجرا قرار دهید.
3. TELEGRAM_CHAT_ID را نیز تنظیم کنید.
4. سرویس را با `python bot.py` اجرا کنید.
